## 🚀 ПОРЯДОК ДЕЙСТВИЙ (production pipeline)

1. **Изображения:** сгенерировать Кадр 1 → зафиксировать seed/SREF → сгенерировать остальные 6 кадров (`01_image_prompts.md`).
2. **Озвучка:** ElevenLabs, голос Josh/Adam, генерация по абзацам (`02_voiceover_script.md`).
3. **Звук:** собрать эмбиент + 22 SFX по таблице таймингов (`04_sound_design.md`).
4. **Монтаж:** CapCut/AE по раскадровке (`03_video_timeline.md` + `06_editing_recommendations.md`).
5. **Тексты:** ключевые фразы + экспорт SRT (`05_on_screen_text.md`).
6. **Loop-тест:** склейка двух копий подряд, проверка стыка на 0.5× скорости.
7. **Экспорт:** H.264 1080×1920 @30fps, −14 LUFS.
