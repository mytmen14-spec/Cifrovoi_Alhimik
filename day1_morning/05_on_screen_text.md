## 🎨 СТИЛЬ ТЕКСТА (единый для всего видео)

| Параметр | Значение |
|---|---|
| **Шрифт заголовков** | Cinzel / Marcellus (фэнтези-серифный) или Montserrat ExtraBold (кириллица!) — проверить поддержку Cyrillic |
| **Шрифт субтитров** | Inter SemiBold / Manrope Bold |
| **Размер ключевых фраз** | 90–120 px (на холсте 1080×1920) |
| **Размер бегущих субтитров** | 54–64 px, максимум 2 строки по 3–5 слов |
| **Цвет основной** | #F5EFE6 (тёплый белый) |
| **Акцентные слова** | #D4A574 (золото) + glow outer 30 px, opacity 60% |
| **Обводка/тень** | Чёрная тень 4 px blur 8, opacity 70% (читаемость на фоне тумана) |
| **Позиция** | Центр y ≈ 960 px; CTA — y ≈ 1250 px (см. safe areas в таймлайне) |
| **Анимация появления** | Word-by-word pop (scale 110→100, 3 фрейма) или typewriter; исчезновение — fade 5 фреймов |

**Правило:** одно ключевое слово в каждой фразе выделяется золотом и чуть крупнее (на 15%).

## 📑 ПОЛНЫЕ БЕГУЩИЕ СУБТИТРЫ (синхронно с озвучкой)

Формат: `старт → конец` | текст (| = смена строки, каждая строка ≤ 5 слов)

```
0:00.5 → 0:02.0 | Ты не ленивый.
0:02.0 → 0:03.5 | Твой внутренний|компас просто сломан.
0:04.5 → 0:06.5 | Каждая незавершенная|задача —
0:06.5 → 0:08.5 | это открытая вкладка|в твоем мозге.
0:08.5 → 0:10.0 | Ты не видишь их,|но они работают.
0:11.0 → 0:13.5 | Эти невидимые моли|пожирают твою энергию.
0:13.5 → 0:16.0 | Ты устаешь,|даже когда|ничего не делаешь.
0:17.0 → 0:19.0 | Твой мозг|не отдыхает.
0:19.5 → 0:22.0 | Он постоянно|перезагружается,
0:22.0 → 0:24.5 | пытаясь закрыть|эти вкладки.
0:26.0 → 0:27.5 | Выпиши всё.
0:27.5 → 0:30.0 | Каждую мысль.|Каждую задачу.|Каждый страх.
0:30.0 → 0:32.0 | Перенеси их|из головы на бумагу.
0:33.0 → 0:36.0 | Когда ты выписываешь задачи,|ты закрываешь вкладки.
0:36.5 → 0:38.5 | Твой мозг|снова твой.
0:41.0 → 0:43.5 | Именно поэтому|ты должен помнить
0:43.5 → 0:45.0 | одно правило…
0:45.5 → 0:47.5 | …твой внутренний|компас просто сломан.
```

⚠️ **Важно:** крупные фразы из первой таблицы и бегущие субтитры НЕ должны перекрываться по времени. Решение: бегущие субтитры идут в нижней зоне (y ≈ 1400, ниже safe area UI допустимо только для Shorts), либо дублирование запрещено — выберите один режим:
- **Режим A (рекоменд.):** только крупные фразы (стиль канала) + SRT для глухих.
- **Режим B:** крупные фразы в центре + компактные субтитры внизу (36 px).

## ✍️ ПРОВЕРКИ ПЕРЕД ЭКСПОРТОМ

1. Все тексты внутри safe-area (центральный коридор 620–1300 px по вертикали).
2. Ни одна фраза не висит дольше 3.5 сек без смены кадра.
3. Контраст текста ≥ 4.5:1 на самых светлых участках фона (проверить на Кадре 3.2 — там много золота).
4. Опечатки: прогнать текст через проверку; слово «перезагружается» — самое длинное, следить, чтобы не переносилось неудачно.
5. Эмодзи 🌫️ рендерится только в системном шрифте — в After Effects использовать PNG-стикер вместо эмодзи.
