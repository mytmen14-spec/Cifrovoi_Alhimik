## ✨ ЭФФЕКТЫ И АНИМАЦИЯ СТАТИЧНЫХ ИЗОБРАЖЕНИЙ

### Оживление кадров (Ken Burns Pro)
Каждый статичный PNG из Midjourney разбивается на 3 слоя в Photoshop (фон / средний план / передний план + фигура) и анимируется параллаксом:
- Скорость движения слоёв: фон 2%, средний 5%, передний 8% от размера кадра.
- Всегда добавляйте **медленный зум** (100→106% за кадр) — «мёртвых» статичных планов быть не должно.
- В CapCut: эффект «3D Zoom Pro» как быстрый аналог; в AE — камера + null-объекты.

### Слои поверх всех кадров (global overlays)
1. **Золотые частицы/светлячки** — эмиссия Particular (AE) или стикер-видео «golden dust black screen» с blend mode Screen, opacity 30–50%.
2. **Туман** — 2 слоя animated fog (blend Screen 20% для холода / Soft Light 15% для тепла), разные скорости drift.
3. **Glow на источниках света** — Gaussian blur дубликата яркости: eyes, Lumen, notebook, compass brass. Radius 40–60 px, Screen 50%.
4. **Виньетка** — постоянная, −15% по углам; усиливается до −30% в блоке 2.3 (клаустрофобия).
5. **Film grain** — opacity 4–6% (скрывает banding градиентов при компрессии YouTube).

### Специальные эффекты по блокам
- **Блок 2.3:** digital glitch — RGB channel offset ±4 px случайными всплесками каждые 0.5 с; scanlines overlay 10%.
- **Блок 3.1:** синхронизация «росчерк пера → chime → мотылёк исчезает» — строго на кадры (каждое событие кратно 1 фрейму). Это ASMR-ядро ролика, не сбивайте ритм.
- **Блок 3.2:** bloom-волна Люменов — keyframe brightness каждого цветка со сдвигом 0.15 с; общий exposure +20%; gold particles swirl (эмиссия по спирали, скорость 30°/с).
- **CTA:** spring-анимация плашки (CapCut: «Dynamic > Spring» или AE expression elastic out & bungee).

## 🎨 ЦВЕТОКОРРЕКЦИЯ (3 ступени эмоциональной дуги)

### Стиль №1 — «Меланхолия» (0:00–0:25)
| Параметр | Значение |
|---|---|
| Temperature | −20 (холод, туманно-синий #4A6FA5 доминирует) |
| Tint | +5 (лёгкий фиолетовый #2D1B4E) |
| Saturation | −15% |
| Contrast | +10, blacks lifted +8 (дымка) |
| Highlights | −15 (приглушённое золото) |
| Sharpen | +10 на стеклянных деревьях |
| LUT-ориентир | «Teal-Violet moody», lowered midtones |

### Стиль №2 — «Перелом» (0:26–0:32)
Плавная автоматизация в течение блока: Temperature −20 → +10, Saturation −15% → +5%, Dusk (дымка) 20% → 8%.
Свет становится направленно тёплым справа (god-rays).

### Стиль №3 — «Надежда» (0:33–0:45)
| Параметр | Значение |
|---|---|
| Temperature | +15 (золото #D4A574 правит бал) |
| Saturation | +10%, но ONLY в gold/green каналах (HSL вторичная: +25% yellow/orange, −10% blue) |
| Contrast | +5, blacks чистые (−0) — мир «прояснился» |
| Glow/bloom | +25% на источниках света |
| Whites | +10 (воздух) |

### LOOP-возврат (0:45–0:48)
Автоматизация обратно к Стилю №1 за последние 2 секунды (Temperature +15 → −20), чтобы стык с 0:00 был невидим.

### Единые точки белого/чёрного
Во всех стилях держите black point 5–10 IRE (не 0 — «мрачное фэнтези» требует молочных теней) и white point ≤ 95 IRE (без клиппинга золота).

## 🛠️ РАБОЧИЙ ПРОЦЕСС (порядок сборки)

1. **Импорт:** 7 PNG (1080×1920, из них 4 с psd-слоями параллакса) → секвенция на таймлайн по раскадровке `03_video_timeline.md`.
2. **Голос:** WAV из ElevenLabs → дорожка VO → подгонка пауз (j-cut: голос чуть раньше смены кадра в блоках 2.x; l-cut в блоке 3.x).
3. **Keyframes движения камеры** под удары озвучки (каждое «ключевое слово» = зум-пульс +2%).
4. **SFX** по таблице `04_sound_design.md` — сначала компас/мотыльки/письмо (ритмические), потом атмосферные.
5. **Музыка** → sidechain-компрессор от VO.
6. **Тексты** по `05_on_screen_text.md` → затем SRT-экспорт отдельно.
7. **Грейд** тремя стилями + overlays (grain, vignette, fog, particles).
8. **Loop-чек:** экспорт → склейка двух копий → просмотр стыка на 0.5×.
9. **Экспорт:** H.264, 1080×1920, 30 fps, битрейт 12–16 Mbps, аудио AAC 320 kbps, −14 LUFS.
